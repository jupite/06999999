# 文章评论

公开文章详情页支持 1–2000 字纯文本评论，不解析 HTML 或 Markdown。访客查看公开评论，登录且具备 `comment.submit` 权限的用户可提交。暂不开放回复、通知、编辑和删除评论。

站主本人评论直接公开；普通用户进入人工审核。当前未接 AI 执行器，不声称执行 AI 审核，即使预留配置存在也仍转人工。每账号每分钟最多新建 5 条；同一提交标识与正文重试只返回原记录，避免网络重试重复创建。

## 审核

站主从后台「评论审核」进入，每页 20 条，按提交时间从早到晚展示。通过前重新检查作者当前的账号状态、评论权限和文章公开状态。拒绝须填写原因；文章已下架或作者被封禁时仍可拒绝并清理待审队列。审核保存版本、审核记录及操作审计，旧页面无法重复处理。

公开列表每页 20 条，按时间倒序，仅显示 PUBLISHED 评论。文章下架后停止公开查询及新增评论，已有记录保留；作者被封禁不自动删除历史已公开评论。

## 接口和权限

- `GET /api/articles/{slug}/comments?page=1`：公开评论和分页状态。
- `POST /api/articles/{slug}/comments`：登录、同源请求，提交 UUID v4 标识和正文，返回评论 ID 及审核状态。
- 审核通过 Server Action 执行，页面与操作分别校验 `site.manage`。
- 请求体最多 16 KiB，评论在服务端去除首尾空白再校验。身份、公开状态、幂等、频率与审核规则在事务中检查。

完整契约见 [Web API](./api/web.openapi.yaml)。评论内容按文本转义展示；请求失败保留输入，成功后清空并提示公开或待审核。

## 验收

运行 `pnpm test:comments`（需测试数据库配置）。覆盖访客、普通用户待审、站主直发、重复提交、版本冲突、拒绝、撤权和封禁、文章下架及历史记录保留；数据库测试使用事务回滚。
