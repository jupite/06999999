# 二次元视觉参考

更新日期为 2026-11-12。

## 参考与状态

用户提供参考网站 https://www.xinghuisama.top/ 及首页截图，关注配色与布局。以下观察基于截图；建议参数不是对原站 CSS 的提取，也不代表用户已逐项批准。引用参考的视觉组织，不直接复制其名称、文案、插画或功能清单。

## 已确认角色方向

用户指定《魔法少女小圆》的晓美焰作为角色视觉方向。宠物已确定为平滑的 Q 版动画小焰，采用长发、黑发带的经典造型，非像素风；具体背景插画、服装细节与动画素材尚未选定。

建议沿用参考站的毛玻璃卡片与错落网格，调整为深紫黑底、冷灰紫卡片、紫罗兰强调色与银白文字。人物背景放在主体两侧可见区域，中央内容区增加遮罩，避免角色被完全遮挡或文字难以辨认。

宠物采用平滑的 Q 版动画晓美焰。二维精灵/分层动画或 Live2D 等技术方案尚未选定；平滑外观不等于必须采用 Live2D。待机、点击反馈、拖动、收起沿用既有建议，不默认增加 AI 对话。钟表、圆环等可作为少量装饰提案，不自动扩展为功能。

## 截图中的视觉特征

- 全屏二次元插画背景，大幅模糊并覆灰蓝色遮罩；插画提供色彩氛围，主要文字位于深色卡片。
- 顶部通栏深色半透明导航，内容主体集中在页面中间，两侧留白较宽。
- 主区域顶部有窄于内容区的搜索框；第一排是较宽的个人介绍卡和音乐卡，下方是一条横贯内容区的歌词栏。
- 下半部分为非对称卡片网格：左侧竖长图文卡，右上横向摄影卡，右下中等图文卡和较小模式切换卡。
- 卡片使用较大圆角、轻描边和阴影；背景图片上的文字带深色渐变衬底。
- 主强调色为蓝紫，少量紫粉色用于数字或局部点缀；标题偏明亮，说明文字呈灰白。
- 截图可见散布的发光光点、底部线条装饰和右下角像素宠物；静态截图不能确认其动画行为。

## 对本项目的适配建议

- 导航采用已确认的首页、项目、文章、照片墙、音乐、友链、关于，加登录/投稿入口。
- 首排采用个人信息卡 + 音乐卡；下方错落网格放精选文章、照片预览和项目卡。
- 主页卡片用于内容导览；文章详情使用稳定、对比度足够的阅读面板，避免背景透过正文过多。
- 音乐卡切页后使用已确认的可拖动悬浮组件，宠物与播放器默认分置两侧，支持移动与收起。
- 手机端转为单列，简化个人资料区域和导航；触控播放器和宠物不能遮挡编辑与提交按钮。
- 后台和 Markdown 编辑器沿用前台深紫色配色、基础圆角和表单样式。
- 发光点与线条为可选装饰，减少动效模式下关闭非必要动画。

参考截图里的搜索、歌词、轮播、时钟、运行时长、技术栈标签、额外导航栏目和明暗切换不自动纳入首版范围；需要时另行确认。现有待确认功能不因参考截图出现而视为已批准。

## 后台管理

已确认后台沿用前台深紫色风格，保持前后台视觉统一。复用现有背景、卡片、文字、强调色和描边变量，按钮、输入框及状态提示使用一致的样式。

布局方案采用左侧菜单、顶部操作栏和右侧工作区。手机端将侧栏收进抽屉。菜单分组、页面信息及操作细节仍按功能确认。

- 左侧菜单按概览、内容管理、审核中心、用户与权限、媒体资源、站点设置组织。
- 顶部操作栏提供返回网站、语言切换和账号入口。
- 列表页集中放置搜索、筛选和主要操作。表格使用浅描边和紫色选中态。
- 编辑页按功能分组，显示当前值、生效来源和保存结果。用户权限页重点展示角色预设、个人例外和最终权限。
