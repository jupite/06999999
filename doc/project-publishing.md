# 项目卡片发布

## 投稿

1. 站主在「站点管理 → 项目网站名单」添加允许的域名，并按需配置子域名范围或禁止规则。禁止规则优先。可先用同页的「检查网址」验证。 [规则说明](./publishing-rules.md#项目网站白名单)
2. 登录后打开「项目 → 提交项目」，填写标题、简介和完整 HTTP 或 HTTPS 网址。具备图片上传权限和配额的用户也可上传封面。
3. 站主提交后直接发布，普通用户提交后进入人工审核。可从「我的项目」查看状态或拒绝原因。

## 审核和公开展示

站主在「站点管理 → 项目审核」查看作者、简介、网址和封面。通过前会重新检查作者权限和网站名单，拒绝时需要填写原因。

公开项目列表仅展示当前已发布版本。卡片显示标题、简介、作者、目标域名和可选封面，点击后在新标签页打开项目网站。站点会验证提交的地址，已有项目在名单变化后继续展示。作者可确认撤回待审项目或撤下已发布项目，编辑暂未接入。

项目封面共用现有图片存储、权限和配额。待审封面只对上传者和站主开放。配置步骤见[文章图片上传](./article-images.md)。

## 验证

运行 `pnpm test:projects` 验证项目网站名单、投稿、审核和公开列表。测试数据在开发库事务中回滚。

## 项目点赞

公开项目卡片支持登录后点赞和取消，外链与点赞按钮分开操作。访客可查看数量；权限和接口见[文章与项目点赞](./article-likes.md)。

## 撤回与撤下

「我的项目」支持确认和取消操作。只有作者且当前具备 content.editOwn 权限时可以撤回/撤下，站主不能通过个人入口撤下他人项目。不依赖 project.submit、图片权限或当前网站名单；撤回会退出审核队列，撤下会退出公开列表并停止点赞读写。

内容标为 WITHDRAWN，保留版本、审核、审计、封面与点赞记录，不返还上传额度，不提供恢复入口。服务端检查版本及原状态；审核和撤回按作者串行处理，旧页面无法再次发布或误撤下已改变状态的内容。
