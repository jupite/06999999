# API 文档

以下是待确认的展示格式。示例接口已实现。

## 展示格式

| 区块     | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 接口概览 | HTTP 方法、路径、所属服务、用途和调用权限                |
| 请求     | 路径参数、查询参数、请求头或请求体，以及必填项和约束     |
| 响应     | 状态码、响应类型、成功和失败示例，以及各状态下的处理方式 |
| 调用示例 | 可复制的请求命令。认证示例使用占位符                     |

首版可用 Markdown 审阅接口说明。需要生成客户端或校验接口契约时，再考虑把结构化的接口定义交给 OpenAPI，网页继续提供简明说明和示例。

## 示例 · Web 健康检查

- 方法和路径 `GET /api/health`
- 用途为确认 Web 服务可以响应请求。
- 公开接口，无请求参数。

| 状态码 | 响应类型           | 含义           |
| ------ | ------------------ | -------------- |
| `200`  | `application/json` | Web 服务已响应 |

```bash
curl http://localhost:3000/api/health
```

```json
{
  "status": "ok",
  "service": "web"
}
```
