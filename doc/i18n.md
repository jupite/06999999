# 当前 i18n 方案

## 语言选择

网站支持简体中文和英文，默认使用简体中文。访客通过顶部导航切换语言，Server Action 将选择写入 `site-locale` Cookie，有效期一年。Cookie 缺失或取值无效时回到默认语言。同一个 `/articles` 地址会按当前访客的偏好显示。

词典文件统一使用小写语言代码命名。文件名与运行时 locale 通过服务端加载表对应。

| 界面语言 | 运行时 locale | 词典                                                 |
| -------- | ------------- | ---------------------------------------------------- |
| 简体中文 | `zh-CN`       | [zh.json](../apps/web/src/i18n/dictionaries/zh.json) |
| English  | `en`          | [en.json](../apps/web/src/i18n/dictionaries/en.json) |

## 加载和渲染

[服务端加载器](../apps/web/src/i18n/server.ts)读取 Cookie，并动态导入当前语言的 JSON。服务端组件用词典渲染界面和页面元数据。根布局设置 `<html lang>`，并通过 [LocaleProvider](../apps/web/src/i18n/client.tsx) 将当前词典传给编辑器、审核按钮等客户端组件。

文章日期根据 locale 格式化，统一采用 `Asia/Taipei` 时区。文章标题、正文和人工审核意见按原文展示。

## 维护词条

- 词条键只使用英文字母，采用小驼峰命名，例如 `authorLabel`。两份 JSON 使用相同的键，翻译写在值里。页面使用 `t("key")` 读取 `messages` 中的词条。
- 需要插值时，两份词条使用相同的参数名，例如 `{author}`。调用时将参数传给 `t`，例如 `t("authorLabel", { author })`。
- `system` 保存权限和错误提示。服务端返回稳定的词条键，例如 `accountBanned`，界面根据当前语言显示译文。
- 运行 `pnpm typecheck` 检查词典键和调用是否一致。新增或修改词条时，在浏览器切换两种语言，检查目标页面及涉及的提示。
