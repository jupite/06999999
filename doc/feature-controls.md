# 全站功能开关

后台 `/zh/admin/features`、`/en/admin/features` 仅站主可访问，管理八项能力：文章投稿、项目投稿、照片投稿、友链申请、评论、图片上传、点赞/取消及本人内容编辑。

未配置的开关默认开启；开启只是恢复原有授权规则，不自动赋予普通用户上传权限，也不绕过个人禁止、容量、归属或项目网站名单。关闭优先于个人允许和站主业务权限，账号封禁仍优先。

## 影响范围

- 文章投稿关闭会阻止新建草稿、发布和投稿；已有草稿编辑继续由 content.editOwn 控制。
- 内容投稿或评论开关关闭时，待审内容仍保留，审核通过会重新检查而被阻止；站主仍可拒绝。
- 上传关闭不删除图片、不改变现有图片公开状态。照片投稿及带图标友链仍检查统一图片权限。
- 点赞关闭会同时暂停点赞和取消，公开数量与本人原状态继续可读。
- 本人内容编辑关闭会阻止编辑、删除以及项目、照片、友链的撤回/撤下。
- 登录、公开浏览与 site.manage 不纳入开关。音乐导入暂未纳入；角色预设见[角色预设与分配](./role-presets.md)。

设置保存到 FeatureFlag，后续请求重新读取，不固化在 JWT。已经开始的请求不承诺被即时取消。修改采用原值校验，旧页面返回冲突并刷新，不静默覆盖。操作写入 feature.update 审计。

## 接口与迁移

`GET /api/admin/features` 读取全部开关，`PATCH /api/admin/features/{key}` 提交 enabled 和 expectedEnabled。需要站主会话，写入校验同源；请求体最多 2 KiB。已实现契约从后台草案移至 [Web API](./api/web.openapi.yaml)。

新增迁移 `20261113000000_feature_flags`。部署新代码前运行 `pnpm db:deploy`；新增表不改变既有授权数据。未应用迁移时不可运行新版本。

## 验收

`pnpm test:features` 在独立 schema 中验证实际投稿、上传、点赞、编辑和审核检查，确认个人允许和站主也受关闭限制、后台仍可用、旧值冲突及审计记录正确。测试结束清理 schema。
