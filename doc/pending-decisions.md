# 待确认事项

更新日期：2026-10-01。以下默认建议尚未成为用户确认的需求；不需要一次回答全部问题。

## 已确认首版范围

- 二次元风格：首版仅一套，其他风格延后；角色方向为《魔法少女小圆》的晓美焰。
- 七个栏目：首页、项目、文章、照片墙、音乐、友链、关于。
- GitHub 登录，登录用户可发布自己的内容。
- 网站内可拖动悬浮宠物，带交互；形象确定为长发、黑发带经典造型的平滑 Q 版动画小焰。
- 网易云单曲和歌单均支持；切页保持播放并缩小为可拖动组件，支持暂停、继续和切歌。
- 项目网站白名单由后台设置，默认精确匹配域名，可逐条开启包含子域名；未匹配禁止提交。
- 统一图片上传权限由站主授予，所有图片入口共用每用户独立容量上限。
- 内容统一进入对应栏目并显示作者。
- 其他用户添加的所有内容先经 AI 审核，未通过转站主人工审核。
- 增加用户权限管理系统，可分别设置权限、白名单与黑名单；具体计算规则见 [权限系统](./permission-system.md)。
- 权限优先级及边界已确认：封禁/显式禁止优先，白名单不绕过配额、网址限制和审核，统一图片上传权限，后台解释生效原因。
- 文章编辑方式已确认：Markdown 编辑并预览。
- AI 服务由后台配置 API 地址、模型、密钥和审核规则；未配置时进入人工审核，供应商可后续选择。
- 站主本人发布免审，可直接发布；其他用户不因进入白名单而免审。
- 图片存储确定为服务器本地磁盘。
- 每用户容量、单张图片大小、全站图片总容量均支持后台设置和变更；初始值后续配置。调整限额约束新增上传，调低限额不自动删除已有图片。
- 文章与照片内容支持分类和标签；独立相册结构尚未确认。
- 支持点赞且无需审核；首版加入 GitHub 登录评论，其他用户评论 AI 初审未通过转人工，站主免审。
