# 后台操作记录

入口为 `/zh/admin/audit` 或 `/en/admin/audit`，仅站主可访问，服务端查询再次检查 `site.manage`。

展示时间（UTC+8）、操作者昵称与站内 ID、操作类型、目标 ID；展开可查看数据库已有的变更前后 JSON 值。账号已删除时保留操作者 ID 并提示账号不存在。操作类型保留原始标识，便于对照日志。

- 按用户权限、媒体配置、音乐、文章、项目模块筛选。
- 操作者与目标均按 ID 精确筛选；筛选条件保留到分页链接。
- 每页 20 条，按时间和记录 ID 倒序；窄屏在表格区域横向滚动。
- 无匹配记录时显示空状态。

只读取现有 AuditLog，不新增、修改或删除历史记录。没有记录审计的操作不会补出历史数据；暂不包含登录日志、导出和定时清理。密码及密钥不应写入审计数据。

验收：访客和普通用户不能读取；站主可以展开记录、按模块及 ID 筛选并翻页；手机端页面不出现整体横向溢出。
