# 音乐播放器

站主登录后在「站点管理 → 音乐管理」粘贴网易云单曲或歌单的完整链接，点击「导入曲目」。歌单一次导入前 100 首，系统按网易云单曲 ID 去重。后台可以逐首移除曲目。导入保存的是当时的曲目列表，需要同步歌单新增曲目时可重新导入。

音乐页展示已导入曲目和当前曲目的歌词。有时间戳的歌词会跟随播放进度高亮。播放器支持暂停、进度拖动和切歌，切到同一语言的其他页面后可继续用悬浮控件操作。刷新页面或切换语言会重新建立播放实例。

悬浮播放器的三档布局、封面点按与拖动规则见[待确认的三档方案](./publishing-rules.md#悬浮播放器三档形态待确认)。

支持 `music.163.com/song?id=…`、`music.163.com/#/playlist?id=…` 和相应的移动端完整链接。不可播放时可打开网易云原页面。

## 服务配置

1. 部署受信任的 [NetEase Cloud Music API Enhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced) 社区服务。
2. 在 `apps/web/.env` 或部署环境设置 `NETEASE_MUSIC_API_URL`，例如 `http://127.0.0.1:3001`。容器部署时使用 Web 服务可访问的内部地址。
3. 执行数据库迁移并重启 Web 服务。在后台导入可公开播放的单曲和歌单，然后到音乐页验证播放、歌词和悬浮控制。

Web 服务通过 `/song/detail` 和 `/playlist/track/all` 获取曲目信息，通过 `/lyric` 和 `/song/url/v1` 按需获取已导入曲目的歌词和音源。浏览器直接向网易云 CDN 请求音频。站内播放依赖 API 所在地区、歌曲版权状态和 CDN 可用性。试听资源会显示为不可播放。
