# 友链投稿与审核

公开入口为 `/zh/friends`、`/en/friends`，每页 20 条，只展示已公开版本的站点名称、介绍、可选图标和提交者。外链另开页面并使用 ugc、noopener、noreferrer。

## 申请

登录且具备 `friend.submit` 权限即可申请，无需图片权限也能提交不带图标的友链。站点名称最多 160 字，介绍最多 2000 字，介绍按纯文本显示。网址只接受 HTTP/HTTPS，不允许账号密码或自定义端口；服务端不抓取页面、图标或检测站点在线状态。项目网站白名单不用于友链申请。

图标可通过既有图片 API 上传，必须是本人已上传的可用图片，并通过统一 `image.upload` 权限及容量检查。移除或更换图标不自动删除上传文件，不使用外部图片 URL。

站主直接公开；普通用户进入人工审核，目前未接入 AI 执行器。相同申请标识与相同内容重试不会重复创建；不同用户或不同输入不能复用原标识。「我的友链」查看本人申请的状态和拒绝原因。

## 审核

站主从后台「友链审核」查看名称、网址、介绍和图标，可通过或填写原因拒绝。通过前重新检查作者账号、友链权限，以及可选图标的归属、可用状态和上传权限。拒绝可处理已被封禁或撤权作者的待审申请。状态转换校验版本并写入审核记录与操作审计，旧页面无法重复处理。

待审及拒绝内容不公开。已公开内容不会因作者后来被封禁而自动删除。支持确认后撤回本人待审申请或撤下已发布友链，首版不提供已发布友链编辑、物理删除、在线检测或自动互链检查。

## 接口与验收

投稿与审核通过 Server Action 执行，每次在服务端检查权限；文件接口复用 `POST /api/media` 和 `GET /api/media/{id}`，不新增 HTTP 业务接口。

运行 `pnpm test:friends` 验证网址约束、作者隔离、公开状态、申请幂等、图标归属、撤权与封禁；数据库测试全部回滚。网页验证申请后查看状态、审核前不公开、审核通过后列表和外链可用。

## 撤回与撤下

「我的友链」提供确认和取消操作。撤回/撤下需要当前 content.editOwn 权限且只能操作本人内容，站主也不能通过这个入口操作他人的申请。不再要求 friend.submit 或图片权限；已有记录和图标文件保留，状态变为 WITHDRAWN，退出公开列表和审核队列，暂不提供恢复。原状态或版本变化会拒绝操作，并保留审计及状态记录。

## 拒绝后重新投稿

个人列表中已拒绝记录提供「修改后重新投稿」，显示原拒绝原因，并带入原标题、说明、已有图片/图标及其他字段，修改后创建新记录，原稿和拒绝原因保留。仅作者且当前具备内容编辑及相应投稿权限时可使用；照片仍需上传权限，友链可移除图标后无图标申请。提交时重新校验来源仍为本人已拒绝内容，不接受他人、待审、公开或已撤回内容。

复用已有图片关联不会再次上传或增加容量占用；更换图片仍按原上传规则计入额度。新稿按当前身份站主直发、普通用户人工审核，不属于恢复旧稿。提交记录审计保留 sourceId，便于关联原拒绝记录。
